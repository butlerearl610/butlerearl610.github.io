仿冒页面往往在细节处露出破绽。掌握以下核对方法，可显著降低误入钓鱼站点的风险。

警惕以下仿冒特征

以下情形出现任意一项，都应立刻停止操作并退出当前页面。

  • 1域名细微变形：以形近字母替换、擅自增删连字符或叠加多余后缀的方式伪装，肉眼扫读极易忽略，务必逐字符核对。
  • 2主动推送的链接：社交软件私信、群公告、邮件与短信中的跳转链接，以及陌生人发送的二维码，均不应作为访问入口。
  • 3索要助记词或验证码：任何页面、任何人以"账户异常""安全升级""资产核验"为名索要助记词、私钥、登录密码或短信验证码，均为诈骗。
  • 4要求远程控制或屏幕共享：官方不会要求安装远程软件、共享屏幕或代为操作账户，遇到此类要求应立即终止沟通。
  • 5催促限时操作：以"倒计时""名额有限""立刻验证否则冻结"等话术制造紧迫感，是钓鱼页面常见手段。

正确核对官方渠道

把判断前置一次，之后固定使用已确认的入口，是成本最低的防护方式。

四步核对流程
  1. 通过可信渠道获取 Gate 官方网站地址，逐字比对域名拼写，确认无多余字符。
  2. 进入后核对站点标识、公告与客户端下载入口是否齐全且互相一致。
  3. 确认无误后立即加入浏览器收藏夹，此后统一从收藏夹进入。
  4. 登录前检查地址栏是否被二次跳转，若发生跳转则重新从收藏夹打开。
三条不可让渡的底线
  1. 助记词与私钥只由本人离线保管，不截图、不上传云端、不告知任何人。
  2. 短信与邮箱验证码只在本人操作时使用，任何索要行为一律拒绝。
  3. 发现异常立即修改密码、退出全部设备，并冻结提币权限。

Security

安全机制

安全由资产存储、密钥权限、行为监控与持续审计共同构成，任何单一环节都不足以独立承担防护职责。

FAQ

常见问题

关于 Gate 官方网站、Gate官方入口、大门官网与 Gate 站点的高频疑问，逐条整理如下。

Gate 官方网站与仿冒站点如何区分？

仿冒站点常通过细微的字母替换、连字符增删或多余后缀伪装域名。请从已收藏的官方入口进入，逐字核对地址拼写，不要点击陌生人发来的短链、二维码或群内转发的跳转页；页面要求输入助记词时，一律视为钓鱼。

Gate官方入口为什么建议手动核对？

搜索引擎广告位与第三方导航站可能指向高仿页面。建议将核对过的官方入口自行收藏，之后固定从收藏夹进入，避免每次通过搜索结果二次判断，降低误入仿冒页面的概率。

官方客户端下载应该注意什么？

请从 Gate 官方网站公布的下载入口获取安卓或 iOS 客户端，安装前核对安装包名称与发布说明。不要使用来源不明的第三方链接、群文件转发包或所谓内部版安装包。

助记词与验证码可以提供给客服吗？

不可以。助记词、私钥、登录密码与短信验证码属于账户最高权限凭据，任何自称官方客服、技术支持或安全中心的人员索要，均属诈骗行为。官方不会通过电话、私信或社交软件索要上述信息。

现货交易与合约交易的区别是什么？

现货交易按当前市场价格买卖资产，成交后持有标的本身；合约交易通过杠杆跟踪价格变化，盈亏同步放大，并涉及保证金与强制平仓机制，风险等级明显更高。

稳定币与热门 Token 在平台内如何流转？

用户可在账户内完成稳定币与各类 Token 之间的兑换、划转与提现操作，具体可用网络、手续费与到账时间以客户端内页面提示为准。链上转账前请核对地址与所属网络，转错网络通常无法找回。

冷热钱包隔离与多重签名起什么作用？

冷钱包长期离线保存大部分资产，私钥不接触网络；热钱包仅保留日常流转所需额度。多重签名要求多把私钥共同授权才能完成关键操作，避免单一人员或设备独立动用资金。

页面中的示意图形是实时数据吗？

不是。页面内的图形与条目均为界面演示用途的示意内容，不代表任何时点的真实行情、价格或成交量，不可作为交易依据。实际数据请以官方客户端内展示为准。
